# 데이터·AI 사용 정책

이 문서는 개발 기준이며 외부 서비스의 최신 약관을 대신하지 않는다. 출처별 사용 조건과 승인 범위를 M2 수집 전에 확인·기록한다.

## 허용 범위 판단

1. 공공데이터는 라이선스, 출처 표시, 갱신·재배포 조건, 개인정보 포함 여부를 데이터셋별로 확인한다.
2. 외부 검색/지도 API는 호출·캐시·저장·표시·재가공·AI 입력 권한을 **각각** 확인한다. API로 볼 수 있다는 사실만으로 영구 저장이나 AI 분석을 허용하지 않는다.
3. 게시물 본문·사진·후기는 저작권과 개인정보를 포함할 수 있다. 권한이 확인되지 않으면 수집·복제·요약·모델 입력을 하지 않는다. 공개 화면에는 필요한 범위의 출처 링크와 검증된 사실만 표시한다.
4. 네이버 블로그 검색 API 결과의 저장·재사용·재가공·AI 처리 허용 여부는 최신 약관과 승인 조건을 확인하기 전까지 **미확인**이다. 그 전에는 실제 본문을 수집·분석하지 않는다.
5. Instagram 등 무단 크롤링은 MVP 범위에서 제외한다. 접근 제한 우회도 하지 않는다.

## 수집·검토 절차

출처, 권한 근거, 허용 사용 범위, 수집·확인 날짜, 외부 ID를 기록한다. API rate limit과 이용량 한도를 지키고 재시도에는 백오프를 둔다. 중복·위치·폐업 여부를 점검한 후 운영자가 게시 상태를 승인한다. 오류 신고가 들어오면 `reported`로 표시하고 재검토 후 수정·숨김·폐업 처리한다. 출처 삭제나 이용 조건 변경 시 해당 데이터와 파생 특징의 사용을 재평가한다.

## 표시·최신성

사실 주장과 추천 이유에는 가능한 한 출처와 최종 확인 날짜를 연결한다. 시점 의존 정보는 오래되면 재검증하고, 근거가 없거나 충돌하면 `unknown`으로 표시한다. 장소의 실재성 검증과 영업시간·분위기 등 개별 속성 검증을 구분한다.

## AI 환각 방지

LLM에는 권한 있는 자료와 DB 후보만 제공한다. 구조화 출력으로 장소 ID·특징·근거 ID를 검사하고, 존재하지 않는 ID나 근거 없는 장점은 폐기한다. 모델 출력을 그대로 사실로 게시하지 않고 운영자 검토와 평가 기록을 남긴다. 개인정보·비밀키를 프롬프트에 넣지 않는다.
