# SCR-02 장소 상세 (M1~M3 설계)

## 화면 구성

상단에는 장소명·카테고리·주소와 뒤로 가기를 둔다. 이어서 지도 위치, 장소 소개, 특징 태그, 최근 확인된 정보, AI 추천 이유, 주장별 근거·출처·확인 날짜, 외부 지도 길찾기를 배치한다. M1 mock 상세는 가상 데이터 표시를 유지한다. 소개·특징·추천 이유의 근거가 없으면 임의의 장점을 만들지 않고 `확인된 정보가 없습니다`로 보여준다.

## 상태와 상호작용

목록/마커에서 들어오면 선택 장소 ID로 상세를 조회한다. 출처 링크는 새 탭 이동임을 알리고, 길찾기는 외부 지도 앱/웹으로 이동한다. 정보 신고는 M3 검토 절차가 준비되기 전에는 노출하지 않는다. 로딩은 골격/문구, 미존재·비공개는 별도 안내, 네트워크 오류는 재시도 동작으로 처리한다. `unknown`과 오래된 정보는 검증된 최신 정보와 시각적으로 구분한다.

## 반응형·접근성

모바일은 단일 열과 하단까지 읽기 쉬운 순서, 넓은 화면은 본문/지도 2열을 사용한다. 제목 계층, 지도 위치의 텍스트 주소, 링크의 목적 설명, 키보드 초점 표시, 충분한 대비를 제공한다. AI 이유는 근거 항목과 연결되는 문구로 제공한다.

## 수용 기준

- 선택한 장소의 이름·카테고리·주소·지도 위치가 일치한다.
- 공개된 사실에는 출처와 확인 날짜가 연결되고 미확인은 `unknown`으로 구분된다.
- 근거가 없을 때 허구의 특징·AI 추천 이유가 표시되지 않는다.
- 키보드로 뒤로 가기·출처·길찾기에 접근하고 오류 후 재시도할 수 있다.
