# SCR-01 홈·지도 (M1 설계)

## 화면 구성

모바일 상단에 서비스 헤더와 현재 지역을 표시한다. 자연어 검색 입력 아래에 `카페·빵집`, `식당`, `산책·공원` 필터를 둔다. 주 영역은 지도와 실제 장소 마커이며, 선택하면 하단 장소 미리보기 카드에 이름·카테고리·주소·최근 확인일을 보여준다. 지도/목록 전환 버튼은 같은 필터 결과를 유지한다. M1 mock은 카드와 마커에 **가상 데이터**로 명시한다. M0 기본 화면은 지도 대신 서비스 소개만 보여준다.

## 상태와 상호작용

홈 진입 → 카테고리 선택 → 마커 선택 → 장소 미리보기 → 상세 이동. 필터·지역 변경 시 이전 선택을 해제하고 결과를 갱신한다. 로딩에는 진행 문구, 빈 결과에는 조건 변경 안내, 오류에는 재시도 버튼을 제공한다. 위치 권한을 요청하는 기능은 초기 필수 조건이 아니다.

## 반응형·접근성

좁은 화면은 지도와 하단 카드, 넓은 화면은 지도와 목록을 나란히 배치한다. 지도만으로 정보를 전달하지 않고 동등한 목록을 제공한다. 필터는 선택 상태를 텍스트/ARIA로 알리고 마커·카드는 키보드로 조작 가능하게 한다. 검색 입력에 레이블, 상태 변경에 라이브 영역, 충분한 터치 영역과 대비를 제공한다.

## 수용 기준

- 로그인 없이 첫 화면에 접근하고 지역·카테고리·지도/목록을 확인할 수 있다.
- 필터 결과와 마커/목록 개수가 일치하고 선택한 장소 상세로 이동한다.
- mock은 실제 장소로 오인되지 않으며 확인된 중심 좌표만 사용한다.
- 로딩·빈 결과·오류가 구분되고 키보드만으로 목록 탐색이 가능하다.
